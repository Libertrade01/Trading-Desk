Import section design directions.

Five ways to present the rTrader CSV import strip at the top of Close loop. Each mock shows the section in page context. Today only rTrader is supported — but several layouts reserve space for a future broker/source picker without a redesign.

Multi-broker readiness

Today Single source: rTrader. Copy says “Import from rTrader” or shows an rTrader chip/pill as the implicit default.
Future Broker selector (dropdown or segmented control) switches import parser + help text. Performance Summary / Trades auto-detect stays the same per source.
Best for scale Design 04 (split row) and Design 03 (card header) — source is a first-class control. Design 02 segmented chips scale to 3–4 brokers. Design 01 and 05 work today but need title/copy changes when brokers multiply.
Design 01
Refined context strip
Baseline polish

Closest to production: glass context strip with title, subtext, help link, and Import CTA. Today the title names rTrader; future state swaps the title to “Import session data” and adds a compact broker dropdown beside it — same row, no layout break.

Recommendation summary

Ship today Design 01 — minimal diff from current strip; add broker dropdown in title row when ready.
Plan for 2+ brokers Design 04 first, Design 03 second — source control is structural, not bolted on.
Keep it tiny Design 02 — segmented chips in one row; use overflow menu beyond 4 brokers.
De-emphasize import Design 05 — collapsible bar; broker picker lives in expanded state only.
