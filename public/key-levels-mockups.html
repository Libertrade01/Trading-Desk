Key levels design directions.

Five ways to present today’s levels, using the same premium glass language as the rest of the daily workflow. Description options for the section are listed first.

Key levels description options

Current The prices that matter today. Mark them now so you don't have to remember in the heat of the moment.
Option A Prices that define the day. Mark them before the open.
Option B Support, resistance, and magnets for this session.
Option C The levels you’ll respect — and the ones you’ll attack.
Option D Map the board before you trade it.
Option E Key prices only. If it isn’t here, it doesn’t matter today.
Option F Overnight highs/lows, value edges, and decision points.
